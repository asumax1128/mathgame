ROTA·i

複素数をかけて、平面を回れ。
軌跡でなぞった光点をまとめて回収する、複素数平面の航跡パズル。

遊び方

あなたの船は複素数 z。手札のカードで z を変えて、盤上の光点◆を回収します。

操作

  • スマホ：カードをタップ → 軌跡の予告が出る → もう一度タップ（または行き先の点をタップ）で発進
  • PC：カードにマウスを乗せると予告、クリックで発進。キー 1〜4 でも可（2回押しで発進）、S で手札入替

カードの意味

+1, +i, −2 …足し算＝平行移動（まっすぐ進む）
×i, ×(−i), ×(−1)原点まわりの回転（90°, −90°, 180°）。円を描いて進む
×(1+i), ÷(1+i)回転＋拡大・縮小（45°回って √2 倍 / 1/√2 倍）。ワープ
z̄（共役）実軸で折り返し（上下反転）

得点

  • 移動の軌跡（線・円弧）の上にある光点はすべて回収。ワープ系は着地点だけ。
  • 1手で k 個回収すると k² 倍の得点（1個:1、2個:4、3個:9…）。
  • 回収が続くと CHAIN。倍率 ×1 → ×1.5 → ×2 → ×2.5 → ×3（最大）。空振りや手札入替で 0 に戻る。
  • 6個回収ごとにレベルアップ：新カード解禁、光点の価値が上がる、岩が現れる、燃料+3。

終了

  • 1手ごとに燃料 −1。緑の光点は燃料 +3。燃料が 0 で終了。
  • 盤（円）の外に出る手、岩にぶつかる手、割り切れない ÷(1+i) は打てません（予告で理由が出ます）。

コツ

  • 点線の円は今の |z|。同じ円の上の光点は、回転カードで一気になぞれる。
  • ×i を4回かけると元に戻る。÷(1+i) は a+b が偶数の点でだけ使える。
  • 原点 0 に止まると、かけ算カードは役に立たない（0に何をかけても0）。
